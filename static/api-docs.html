GET /api/search

Search YouTube and return ranked, filtered wallpaper loops. Results are cached in SQLite by query (+ strict/limit) for 24h, and community votes are blended into the ranking live.

ParamTypeDefaultDescription
qstring-Required. The search query.
strictboolfalseAlso require a wallpaper keyword in the title.
limitint25Candidates to pull from YouTube (1-50).
refreshboolfalseBypass the cache and re-search.
Response (envelope)
{
  "query": "synthwave city",
  "strict": false,
  "cached": true,
  "count": 20,
  "results": [
    {
      "title": "Synthwave DeLorean Drive - Live Wallpaper - 4K",
      "channel": "Space Wallpaper 4K",
      "thumbnail": "https://i.ytimg.com/vi/.../hqdefault.jpg",
      "duration": 116,
      "resolution": null,
      "url": "https://www.youtube.com/watch?v=rneArlA6ouw",
      "video_id": "rneArlA6ouw",
      "score": 106,
      "votes": 0,
      "breakdown": {
        "base": 10, "title_keywords": ["live wallpaper", "4k"],
        "title_points": 88, "resolution_points": 0, "aspect_points": 0,
        "duration_points": 8, "vote_points": 0, "total": 106
      }
    }
  ]
}

POST /api/rate

Cast a community vote on a wallpaper. One vote per video per person (deduped by a hash of IP + user-agent; raw IPs are never stored). Re-voting updates your vote. Rate-limited to 20 votes/minute.

Body fieldTypeDescription
video_idstringRequired. The YouTube video id.
voteintRequired. Must be +1 or -1.
Response
{ "video_id": "rneArlA6ouw", "net_votes": 1 }
curl
curl -X POST "__BASE_URL__/api/rate" \
  -H "Content-Type: application/json" \
  -d '{"video_id": "rneArlA6ouw", "vote": 1}'
fetch
const res = await fetch("__BASE_URL__/api/rate", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ video_id: "rneArlA6ouw", vote: 1 })
});
const { net_votes } = await res.json();
